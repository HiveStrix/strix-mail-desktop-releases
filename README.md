# Strix Mail para escritorio

Instaladores de **Strix Mail** para macOS, Windows y Linux. La app se conecta a
[mail.strixapps.com](https://mail.strixapps.com) y se actualiza sola.

**[Bajar la última versión →](https://github.com/HiveStrix/strix-mail-desktop-releases/releases/latest)**

| Sistema | Archivo |
|---|---|
| macOS (Apple Silicon e Intel) | `strix-mail_X.Y.Z_universal.dmg` |
| Windows 10/11 | `strix-mail_X.Y.Z_x64-setup.exe` (o `.msi`) |
| Linux | `strix-mail_X.Y.Z_amd64.AppImage` (o `.deb`) |

Por ahora los instaladores no están firmados:

- **macOS:** la primera vez, clic derecho sobre la app → **Abrir**.
- **Windows:** si aparece «Windows protegió tu PC», **Más información → Ejecutar de todas formas**.

Este repo solo publica versiones: los releases y `latest.json` los genera el CI.
